# Custom Macropad (Hardware)

A physical custom macropad built following https://newtlekim.tistory.com/6/.
Ported to Windows by me.

## Overview
- Built from physical components following a build guide.
- Hand-soldered / assembled and configured.
- Designed to work alongside my custom software: [Macro-Manager](https://github.com/Shio-01/Macro-Manager).
